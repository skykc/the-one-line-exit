One funny single-line resignation letter for make.fun's "The One-Line Exit" bounty: a night baker quits, because after six years of rising at 3 a.m. he has learned the dough is the only thing in that bakery that ever rises.

## Run it

```sh
node main.ts
```

This writes the one-line letter to `/output/entry.txt` (129 characters, one line, UTF-8).
